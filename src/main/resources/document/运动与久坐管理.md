# 运动与久坐管理

## 适用范围与安全检查

本文面向一般成年人。长期未运动、存在心肺疾病、代谢疾病、孕产状态、明显关节或脊柱问题、近期手术或反复运动不适的人，应在增加强度前咨询合格医疗专业人员。

若运动中出现胸痛、严重呼吸困难、晕厥、意识异常、突发单侧无力或说话困难，应立即停止运动并联系当地急救服务。

## 成年人的通用目标

世界卫生组织建议成年人每周累计 150–300 分钟中等强度有氧活动，或 75–150 分钟高强度有氧活动，或两者等量组合；同时每周至少 2 天进行覆盖主要肌群的力量活动。任何活动都比完全不活动好，基础较低时应从少量开始，逐步增加频率、时间和强度。

中等强度可以用“谈话测试”粗略判断：活动时能说话，但不容易连续唱歌。个人疾病和用药可能改变心率反应，因此不要仅凭手表心率决定安全强度。

## 一周起步示例

- 周一、周三、周五：快走 15–30 分钟；初学者可以拆成 3 次 5–10 分钟。
- 周二、周六：进行 15–25 分钟基础力量训练，包括推、拉、蹲、髋和核心动作；选择能保持稳定动作的难度。
- 其余时间：轻松散步和活动度练习，避免把恢复日变成完全久坐。

## 减少久坐

成年人应减少久坐总时间，并尽可能用任何强度的活动替代久坐。可以设置每 30–60 分钟起身活动几分钟、边通话边走动、短距离步行或骑行等环境提示。久坐中断不能完全替代规律运动，但有助于增加全天活动量。

## 逐步增加与记录

每次只增加一个变量，例如先增加每次时间，再增加每周次数，最后才提高强度。记录日期、活动类型、时长、主观用力程度和不适。疼痛持续、夜间痛、肿胀或功能明显下降时，应暂停相关训练并评估。
