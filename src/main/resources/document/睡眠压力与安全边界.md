# 睡眠、压力与安全边界

## 睡眠时长与质量

睡眠需要随年龄变化。美国疾控中心汇总的建议中，18–60 岁成人通常每晚需要至少 7 小时，61–64 岁通常为 7–9 小时，65 岁及以上通常为 7–8 小时。个体差异存在，除了时长，还要关注白天功能、规律性和睡眠质量。

## 改善睡眠的低风险做法

- 尽量固定起床时间，再逐步稳定入睡时间。
- 白天获得自然光照并规律活动；临睡前减少强光、刺激性内容和高强度运动。
- 下午或晚上减少咖啡因；避免依赖酒精助眠，酒精可能让睡眠更碎片化。
- 卧室尽量安静、黑暗、凉爽；床主要用于睡眠。
- 躺下较久仍清醒时，可离床做安静、低刺激的活动，困倦后再返回。

如果失眠持续影响白天功能、频繁大声打鼾并伴随呼吸暂停、夜间窒息惊醒或白天无法控制地嗜睡，应寻求医疗评估，而不是自行长期服用助眠药或补充剂。

## 压力管理

把目标缩小到可控制的下一步：规律吃饭、短时活动、固定睡眠窗口、与可信任的人联系。呼吸练习、正念或写下担忧可以作为辅助，但不能替代对严重焦虑、抑郁、创伤反应或功能受损的专业评估。

## 必须升级处理的情况

健康生活助手不能处理急症。以下情况应停止普通建议并立即联系当地急救服务：

- 胸部压榨感或疼痛，尤其伴随呼吸困难、冷汗、恶心，或疼痛放射至手臂、背部、颈部、下颌或上腹部。
- 突发面部歪斜、单侧手臂无力、说话含糊或理解困难；即使症状短暂缓解也应紧急处理。
- 严重呼吸困难、意识丧失、抽搐、无法正常唤醒或其他快速恶化情况。
- 有立即自伤或伤害他人的想法、计划或手段。应联系当地紧急服务、危机支持资源，并尽快让可信任的人陪伴。
